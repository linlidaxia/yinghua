# 莺花设计规范

版本 1.0.1 · 适用范围：Android（Flutter），网页预览共用同一套 Token。

---

## 1. 品牌与色彩

主色由「主题皮肤」决定，默认是「莺红」，只承担三类语义：**可执行操作**、**正在播放**、**强调信息**。
大面积背景保持纯白或近黑，避免主色泛滥，也避免与网易云的红黑风格混淆。
切换皮肤时字阶、间距、圆角完全不变，只有主色、品牌浅底与界面底色的品牌混合比例变化。

### 1.1 品牌色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `brand` | `#E23B3B` | 主按钮、播放键、选中态、进度条 |
| `brandPressed` | `#C42B2B` | 按下 / 长按反馈 |
| `brandSoft` | `#FDECEC` | 浅色底（快捷入口圆形底、标签） |
| `brandSoftDark` | `#3A1D1F` | 深色模式下的品牌浅底 |
| `gold` | `#F0A93B` | 音质 / Hi-Res 标记 |
| `mint` | `#3AAE8C` | 在线状态点 |

### 1.2 浅色（默认）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `bg` | `#FFFFFF` | 页面底色 |
| `surface` | `#F6F6F8` | 卡片、输入框、搜索框 |
| `surfaceHigh` | `#EFEFF2` | 次级悬浮层 |
| `textPrimary` | `#16161A` | 标题、正文 |
| `textSecondary` | `#6E6E78` | 副标题、歌手名 |
| `textTertiary` | `#A4A4AE` | 辅助说明、时间 |
| `divider` | `#0F000000`（6% 黑） | 分割线、描边 |

### 1.3 深色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `bg` | `#101013` | 页面底色 |
| `surface` | `#1A1A1F` | 卡片 |
| `surfaceHigh` | `#26262C` | 次级层 |
| `textPrimary` | `#F4F4F7` | 标题、正文 |
| `textSecondary` | `#A0A0AA` | 副标题 |
| `textTertiary` | `#6C6C76` | 辅助说明 |
| `divider` | `#14FFFFFF`（8% 白） | 分割线 |

### 1.4 播放页专用
播放页始终是深色沉浸式，不随主题切换：

| Token | 色值 | 用途 |
| --- | --- | --- |
| 背景 | `#0C0C10` | 播放页底色 |
| `playerScrimTop` | `#4D000000` | 封面模糊遮罩（上） |
| `playerScrimBottom` | `#B3000000` | 封面模糊遮罩（下） |
| `vinylBlack` | `#0C0C0E` | 黑胶盘体 |
| `vinylEdge` | `#1E1E23` | 黑胶纹路 |

### 1.5 主题皮肤

设置 → 外观 → 主题风格 一键切换，参考主流音乐 App 的主色气质：

| 皮肤 | 主色 | 按下态 | 气质 |
| --- | --- | --- | --- |
| 莺花（默认） | `#E23B3B` | `#C42B2B` | 品牌红，白底黑字 |
| 网易云音乐 | `#EC4141` | `#D63030` | 云村红，黑胶与乐评 |
| QQ 音乐 | `#31C27C` | `#22A968` | 清新绿，歌单与推荐 |
| 酷我音乐 | `#0F88FF` | `#0B6FD1` | 活力蓝，电台与榜单 |
| 酷狗音乐 | `#00BBD3` | `#0097AA` | 青蓝，蝰蛇音效 |
| 千千静听 | `#4E7FE8` | `#3A66C7` | 经典蓝，极简歌词 |

实现上只替换 4 个 token：`brand`、`brandPressed`、`brandSoft`、`brandSoftDark`，
浅色 `surface` 与深色 `bg` 由「主色 × 皮肤 tint（3%–5%）」混合得到，因此切换后
导航选中态、按钮、进度条、悬浮歌词、Logo、迷你播放条进度线会一起变色，
而字阶、间距、圆角、布局保持完全一致。

对比度：正文 `#16161A` 对白底约 17.6:1，次正文约 5.2:1，均高于 WCAG AA（4.5:1）。
主色上的文字统一使用白色。

## 2. 字阶

字体跟随系统（Android 为 Roboto / Noto Sans CJK，iOS 为 SF / PingFang），
数字启用 tabular figures，避免进度时间跳动。

| Token | 字号 | 行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `display` | 26 | 1.22 | 700 | -0.4 | 首页问候语、页面主标题 |
| `h1` | 22 | 1.28 | 700 | -0.2 | 模块大标题 |
| `h2` | 18 | 1.32 | 600 | -0.1 | 歌单 / 专辑名 |
| `title` | 16 | 1.36 | 600 | 0 | 列表主标题 |
| `titleSm` | 15 | 1.40 | 600 | 0 | 次级标题 |
| `body` | 15 | 1.45 | 400 | 0 | 正文 |
| `bodySm` | 13 | 1.45 | 400 | 0 | 说明文字、歌词预览 |
| `caption` | 11 | 1.40 | 400 | 0 | 辅助信息、导航标签 |
| `overline` | 10 | 1.30 | 600 | 0.6 | 分组标签（大写间距） |
| `button` | 14 | 1.20 | 600 | 0.2 | 按钮文字 |
| `lyric` | 17 | 1.60 | 400 | 0.2 | 未激活歌词 |
| `lyricActive` | 20 | 1.55 | 700 | 0.3 | 当前行歌词 |
| `numeric` | 11 | 1.20 | 500 | 0 | 时间、码率、页码 |

中文正文 15sp、行高 1.45 是全局基准；歌词行高 1.55–1.60，保证长句在窄屏不拥挤。

## 3. 间距

8pt 栅格为基础，常用半步值解决图标与文字的对齐。

| Token | 值 | 用途 |
| --- | --- | --- |
| `xxs` | 4 | 图标与文字内边距 |
| `xs` | 6 | 小间隙 |
| `sm` | 8 | 标签间距 |
| `md` | 12 | 卡片内边距 |
| `lg` | 16 | 卡片之间 |
| `xl` | 20 | 页面左右留白（`page`） |
| `xxl` | 24 | 大块间距 |
| `xxxl` | 32 | 页面底部留白 |
| `gap` | 12 | 横向卡片间距 |
| `section` | 26 | 两个首页模块之间 |

页面左右安全留白固定 20，卡片内部 12–16，模块之间 26，底部为迷你播放条预留 12。

## 4. 圆角与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `xs` | 6 | 小标签、播放进度条 |
| `sm` | 10 | 输入框内元素 |
| `md` | 14 | 封面、输入框 |
| `lg` | 18 | 卡片（默认） |
| `xl` | 22 | 大图卡片 |
| `sheet` | 26 | 底部弹层顶部 |
| `pill` | 999 | 胶囊按钮、状态标签 |

阴影只有两级，避免「处处浮起」：

- `card`：`0 8 18 rgba(0,0,0,0.06)` —— 首页卡片、迷你播放条
- `floating`：`0 10 24 rgba(0,0,0,0.10)` —— 悬浮歌词、底部弹层

## 5. 组件规范

### 5.1 底部导航

- 高度 56 + 系统安全区，白底 + 1px 顶部描边
- 4 个入口：首页 / 资料库 / 搜索 / 我的，`Expanded` 均分
- 图标 23，标签 10；激活态为品牌红 + `w600`，未激活为 `textTertiary`

### 5.2 迷你播放条

- 高度 64，左右 12 边距，圆角 18，`card` 阴影
- 内容：44 封面（圆角 10）→ 歌名 15/600 + 歌手 11/tertiary → 播放/暂停 26 → 下一首 24
- 顶部 2px 进度条，品牌红；暂停时保留进度不消失
- 无播放内容时不占位

### 5.3 首页卡片

- 「为你推荐」横向滚动，卡片宽 152，封面 152×152（圆角 18），下方 15/600 歌名 + 11 歌手
- 「精选歌单」横向滚动，卡片宽 200，封面 3:2 大图，右下角播放按钮 32
- 模块标题 18/600，右侧「全部 ›」11/tertiary；说明文字 11/tertiary，与标题间距 4

### 5.4 播放页

- 全屏深色，封面高斯模糊铺底 + 上下渐变遮罩
- 黑胶：直径约屏幕宽 0.78，黑色盘体 + 细纹 + 中心封面，播放时 20s/圈 线性旋转
- 歌名 22/700 白色，歌手 13/60% 白，可点击进入歌手页
- 进度条 2.5px，激活白色、缓冲 20% 白、未缓冲 20% 白；时间用 `numeric`
- 主播放键 64 圆形品牌红 + 同色光晕；上一首 / 下一首 26；左右为播放模式与队列
- 底部操作区：收藏 / 下载 / 定时 / 列表，图标 22 + 标签 10

### 5.5 歌词页

- 与播放页同一背景，顶部「歌词」+ 服务器名，左侧「逐行同步」胶囊，右侧「校准」
- 未激活 17/45% 白，激活 20/700 纯白 + 轻微外发光
- 行间距 18；点击任意行跳转，自动滚动使当前行居中
- 底部保留迷你播放控制（上一首 / 播放 / 下一首 / 队列）

### 5.6 封面

优先级：本地离线封面 → 服务器封面（磁盘缓存）→ 程序化占位图。

占位图由歌曲 / 专辑 id 作为随机种子，生成 10 套渐变 + 光斑 + 黑胶环 + ♪ 的组合，
保证同一首歌颜色稳定、无封面音乐库也不出现空白块。

### 5.7 排序入口

歌单与搜索结果在列表上方提供「排序」胶囊：默认 `surface` 底 + 次要文字，
非默认状态用 `brandSoft` 底 + 品牌色文字 + `swap_vert` 图标，点击弹出底部选择层。
选项包含默认顺序、标题 A→Z / Z→A、歌手、专辑、时长、年份，当前项右侧用品牌色勾选。

## 6. 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 页面切换 | 380 / 300 ms | `easeOutCubic` / `easeInCubic` |
| 主题切换 | 240 ms | `easeOutCubic` |
| 黑胶旋转 | 20 s / 圈 | 线性 |
| 封面淡入 | 220 ms | 默认 |
| 播放页上滑 | 420 ms | `easeOutCubic` |

所有动效都可被系统「移除动画」设置降级；旋转与模糊在低端机上随播放状态暂停。

---

## 7. 图标

- 统一使用 Material Rounded 线性图标，尺寸 20 / 22 / 23 / 26
- 语义：`play_arrow_rounded` 播放、`pause_rounded` 暂停、`favorite_*` 收藏、
  `download_outlined` 下载、`bedtime_outlined` 定时、`queue_music_rounded` 队列
- 图标永远不单独承担信息，必须同时有文字或无障碍标签

---

## 8. 无障碍

- 所有可点击元素最小热区 44×44
- 文字对比度：正文 ≥ 7:1，辅助文字 ≥ 4.5:1
- 播放页与歌词页的状态栏图标为浅色，其余页面为深色
- 封面、黑胶、播放按钮均提供 `Semantics` 标签（歌曲名 + 状态）
